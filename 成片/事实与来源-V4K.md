# 《此心安处》V4K 事实与来源

## 本片采用的生平口径

| 时间 | 地点与事件 | 本片处理 |
|---|---|---|
| 1037 | 眉州眉山，苏轼出生；1039 苏辙出生 | 苏辙并入眉山段，不另起章节；眉山红底仅作为出生地／起点强调 |
| 1056 | 苏洵携苏轼、苏辙首次出蜀赴京，走陆路 | 片头主年份改为“嘉祐元年”，小号保留“公元1056年”；画面从眉山直接前往汴京，明确略去沿途停驻，不冒充已考证的宋代细线道路 |
| 1057 | 嘉祐二年，苏轼、苏辙同榜进士；母程氏去世后返蜀守丧 | 龙虎榜列欧阳修、苏轼、苏辙、曾巩、张载、程颢；为控制节奏，画面从汴京直接进入凤翔就任，不展开守丧段 |
| 1061—1064 | 凤翔府签书判官 | 是初次地方任职，不称“知凤翔” |
| 1071—1074 | 杭州通判 | 第一次杭州任职，不修苏堤；《饮湖上初晴后雨》按熙宁六年（1073）标注 |
| 1074—1076 | 密州知州 | 捕蝗、赈饥、救助弃婴；《水调歌头》作于熙宁九年（1076） |
| 1077—1079 | 徐州知州；1077 黄河决澶州曹村，洪水至徐州 | 不画成黄河在徐州当地决口；守城七十余日；黄楼图片注明现代重建 |
| 1079 | 移知湖州后被捕，押赴汴京御史台狱 | 御史台摘引《湖州谢上表》及诗文，指控讥讽新法；乌台在汴京，不在湖州或黄州；增加《狱中寄子由二首·其一》填充足以理解作品与处境的时间 |
| 1080—1084 | 黄州团练副使、本州安置、不得签书公事 | 1080 到黄州，1081 躬耕东坡；出狱、贬黄州与启程分开叙述；不把黄州赤鼻矶直接认定为三国赤壁 |
| 1084—1085 | 离黄州，量移汝州；短暂知登州后回朝 | 地图补入汝州、登州，不从黄州直接连到汴京 |
| 1089—1091 | 杭州知州；1090 主持疏浚西湖、以葑泥筑堤 | 苏堤主体工程按元祐五年（1090），而非到任年 |
| 1091—1094 | 颍州、扬州、定州 | 顺序为颍州—扬州—定州 |
| 1094—1097 | 先命英州，途中再贬惠州安置 | 不称“知惠州” |
| 1097—1100 | 琼州别驾、昌化军安置，自雷州半岛渡海至儋州 | 不称“知儋州”；讲学会友采用审慎表述，不写“海南第一所大学”；增加《减字木兰花·己卯儋耳春词》 |
| 1100—1101 | 北归，经岭南、赣南、金陵、润州等地至常州；1101 卒于常州 | 不从儋州直接画到常州；郏县是次年安葬地，不混作去世地 |

## 作品摘句

- 《和子由渑池怀旧》：“人生到处知何似，应似飞鸿踏雪泥。”——嘉祐六年，赴凤翔途中。
- 《饮湖上初晴后雨二首·其二》：“欲把西湖比西子，淡妆浓抹总相宜。”——熙宁六年，第一次杭州任内。
- 《水调歌头·丙辰中秋》：“但愿人长久，千里共婵娟。”——熙宁九年，密州。
- 《狱中寄子由二首·其一》：“与君世世为兄弟，更结来生未了因。”——元丰二年，御史台狱；V3.1 新增。
- 《念奴娇·赤壁怀古》：“大江东去，浪淘尽，千古风流人物。”——元丰五年，黄州。
- 《定风波·莫听穿林打叶声》：“竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生。”——元丰五年，黄州。
- 《食荔支二首·其二》（通行题《食荔枝》）：“日啖荔枝三百颗，不辞长作岭南人。”——绍圣三年，惠州；本片采用通行“荔枝／不辞”文本。
- 《减字木兰花·己卯儋耳春词》：“不似天涯，卷起杨花似雪花。”——元符二年（己卯，1099），儋州；V3.1 新增。
- 《自题金山画像》：“问汝平生功业，黄州惠州儋州。”——北归途经金山，不标作“常州绝笔”。
- 片名“此心安处”出自《定风波·南海归赠王定国侍人寓娘》：“此心安处是吾乡。”——元丰六年；不与《定风波·莫听穿林打叶声》混作同一首。

## 地图、声音与制作边界

- 山体来自 Mapzen Terrarium 真实 DEM 高程（AWS Open Data），地表为 Esri World Imagery 现代卫星影像，不是 AI 编造地图。
- V4K 全国 DEM 从 zoom 5、1792×1280 升级为 zoom 9、28928×20480；卫星影像从 zoom 8、14336×10240 升级为 zoom 9、28928×20480。源数据覆盖原全国场景，东侧另留一列安全边距。
- 全国卫星图与地形同步分为 2×2 四块，以适应本机 GPU 的 16384 像素单纹理上限；没有缩小全国源图。Blender 使用 1800×1350 采样网格，四块合计 2,433,151 顶点，按 3840×2160 实际渲染，不是放大 V3.1 MP4 或帧图。
- 两个孤立无效 DEM 像元只在派生 `.npy` 中以有效邻域中位数修复，原始下载瓦片保留；坐标与数值见 `terrain-4k-z9/dem-repair.json`。
- 主光点仍贴真实 DEM 地形；摄影机路径与前看点单独平滑，避免把地形高频起伏直接传给镜头。
- 宋代地名按今大致地理位置锚定；宋代州界不等于现代行政区。
- 路线是生平地理叙事的大通道，不冒充完成考证的宋代道路、港口细线、河道或疆界复原。
- 北宋黄河河道、西湖水域、海岸港口和城市水系不能直接等同今日影像；片尾已在图注中说明这一边界。
- “文曲星下降”是文学暗喻，不表示真实天象；落地后延续为同一个苏轼主光点。
- 旁白由 VoxCPM2 本地生成，使用非用户本人音色；配乐与音效为原创程序合成，无现成歌曲。
- 三维使用 Blender，档案合成使用 Pillow／NumPy，编码使用 FFmpeg。

## V3.1 叙事修订（V4K 完整沿用）

- 片头出蜀主年份改为“嘉祐元年”，公元 1056 年保留为小号辅助；旁白同步改读年号。
- 眉山红底保留为唯一出生地／起点强调，其他地点不批量加红底。
- 乌台段加入《狱中寄子由二首·其一》及朗读，再衔接出狱、贬黄州与光点启程，不用空等填满时间。
- 儋州段加入《减字木兰花·己卯儋耳春词》及朗读。
- 底部时间刻度增加并合并关键节点：1037、1056–57、1061、1071、1079–80、1089、1094、1097、1101。
- 片尾片名与滚动资料从 05:15.000 开始；资料框缩为右下角矮窄横版，不遮杭州、常州。
- 最终拉远机位适度收紧，去掉地图素材边界造成的左上黑块与左下蓝块；12 个主要站点的投影均在画面内。
- 29 段旁白无重叠；末句在 314.955 秒结束，片尾在其后约 0.045 秒开始。五段重配旁白回转录相似度为 0.9841—1.0000，29 段报告均无待复核项。
